# plant-disease-detection-system

**Kuravisor** — offline AI-powered crop disease detection for smallholder farmers in Zimbabwe.

## Exploratory data analysis

Feasibility study notebook (advanced EDA for the research paper):

```bash
pip install -r requirements.txt
jupyter notebook notebooks/kuravisor_feasibility_eda.ipynb
```

Run from the **repository root** so the notebook resolves `dataset/Plant_leave_diseases_dataset_with_augmentation/`. Exported figures and CSV metrics are written to `notebooks/outputs/`.
